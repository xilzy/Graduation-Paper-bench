# Graduation-Paper-bench

毕业论文 U-MoE-Fusion 对比实验的基准测试产物，与代码仓 [Graduation-Paper](https://github.com/xilzy/Graduation-Paper) 配套。统一的复现契约（输入规范、输出要求、指标口径）见 `BENCH_CONTRACT.md`。

| 目录 | 内容 | 文件数 | 大小 |
|---|---|---|---|
| inputs | 三任务标准化测试输入：gfp_pc（30 对）/ irvis（50 对）/ medical（48 对） | 513 | 375 MB |
| fused | 各对比方法的融合结果 | 15,390 | 1.09 GB |
| fused_final | 最终口径的融合结果 | 9,360 | 0.96 GB |
| reports | 指标汇总与报告 | 565 | 6 MB |
